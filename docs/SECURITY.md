# Security & Safety Policy

## Security Vulnerabilities

### Responsible Disclosure

If you discover a security vulnerability, **do not** open a public issue. Instead:

1. Email: **security@codeai.example.com** (PGP key available)
2. Include:
   - Vulnerability description
   - Steps to reproduce
   - Potential impact
   - Your contact information (optional)

3. **Response Timeline:**
   - Acknowledgment: 24 hours
   - Initial assessment: 5 business days
   - Fix timeline: 30 days (critical), 90 days (high), 180 days (medium/low)
   - Disclosure coordination: We coordinate with you before public announcement

### Bug Bounty

We offer rewards for valid security disclosures:
- **Critical:** $5,000 - $10,000
- **High:** $1,000 - $5,000
- **Medium:** $500 - $1,000
- **Low:** $100 - $500

## Model Safety

### Hallucinations & Inaccuracies

Code AI may generate:
- Syntactically incorrect code
- Inefficient or insecure patterns
- Factually incorrect explanations
- Suggestions that introduce vulnerabilities

**Mitigation:**
- Users should review all generated code
- Report problematic outputs to feedback@codeai.example.com
- Use for suggestions only; don't blindly trust output

### Bias & Fairness

We are committed to minimizing bias in:
- Recommendations (no discrimination by language, framework, or style)
- Error handling (consistent behavior across demographics)
- Model training data (diverse, representative datasets)

**Reporting:** Report bias at bias@codeai.example.com

## Content Safety

### Prohibited Output

The model should NOT generate:
- Slurs, hate speech, or discriminatory content
- Instructions for harm (explosives, weapons, hacking)
- Sexual or adult content
- Highly sensitive PII (SSNs, credit cards, home addresses)

### Monitoring & Response

- Automated filters for prohibited output categories
- User reports reviewed within 24 hours
- Rapid model updates to prevent recurring issues

## Service Availability

**Uptime SLA:**
- 99.5% uptime for API (Premium tier)
- 99.0% uptime for free tier
- Excludes scheduled maintenance (max 4 hours/month)

**Incident Response:**
- Critical outages: Acknowledged within 15 minutes
- Postmortem published within 48 hours

## Transparency

We publish:
- Monthly safety & abuse report
- Quarterly security audit summaries
- Annual transparency report
