# Acceptable Use Policy (AUP)

**Effective Date:** January 16, 2026

## Purpose

This policy defines prohibited uses of the Code AI Service and enforcement mechanisms.

## 1. Prohibited Activities

### 1.1 Illegal Content
- Code for illegal purposes (hacking, fraud, weapons, drugs)
- Content that violates export controls
- Circumventing security or DRM systems

### 1.2 Harmful Code
- Malware, ransomware, or code designed to damage systems
- Code for distributing malware
- Cryptocurrency mining without disclosure

### 1.3 Intellectual Property Violations
- Generating code that infringes patents or copyrights
- Reproducing licensed code without permission
- Violating open-source license terms (e.g., GPL)

### 1.4 Privacy & Harassment
- Generating code to harvest personal data
- Creating tools for harassment or doxxing
- Violating others' privacy or confidentiality

### 1.5 Abuse of Service
- Rate limiting circumvention
- Automated scraping of the API (beyond authorized limits)
- API credential sharing
- Denial-of-service (DDoS) attacks

### 1.6 Fraud & Deception
- Claiming AI-generated code as original without disclosure
- Using the Service for identity theft
- Financial fraud or phishing

## 2. Enforcement

### Warnings (First Offense)
- Email notification of violation
- 48-hour opportunity to respond
- Temporary API rate limiting

### Suspension (Repeated Offense)
- Disabling of API access for 7-30 days
- Restriction of extension usage
- No refunds during suspension

### Termination (Severe or Repeated Violations)
- Permanent account closure
- Forfeiture of account balance
- Legal action if necessary
- Report to law enforcement for illegal activity

## 3. Monitoring

Code AI monitors for:
- Unusual API usage patterns
- Requests flagged by content filters
- User reports
- Automated scanning for known malware signatures

## 4. Appeals

Users may appeal enforcement actions within 30 days by contacting:  
**support@codeai.example.com**

Appeal must include:
- Account ID
- Reason for appeal
- Explanation of why action was unjustified

Appeals are reviewed by the Compliance team within 5 business days.

## 5. Changes

This policy may be updated. Users are notified of material changes.
