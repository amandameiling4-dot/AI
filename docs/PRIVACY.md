# Privacy Policy

**Effective Date:** January 16, 2026

## Overview

Code AI ("we," "us," "our," or "Company") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our code AI services, including the API, VS Code extension, and SDKs (collectively, the "Service").

## 1. Information We Collect

### 1.1 Information You Provide
- **Account Information:** Email, API keys, usage preferences
- **Code Data:** Code snippets and prompts you submit for completions
- **Communications:** Support inquiries and feedback

### 1.2 Information Collected Automatically
- **Usage Data:** Request latency, tokens generated, model used, timestamp
- **Device Information:** OS, browser/extension version
- **Log Data:** Request paths, error messages, performance metrics

### 1.3 Data Retention

- **Code Data (Prompts/Completions):** Retained for 30 days for debugging and billing; user can request deletion anytime
- **Usage Metrics:** Retained for 12 months for analytics and billing
- **Logs:** Retained for 7 days for troubleshooting

## 2. How We Use Your Information

- Provide and improve the Service
- Process billing and manage subscriptions
- Troubleshoot and enhance performance
- Comply with legal obligations
- Monitor for abuse and security threats

**We do NOT:**
- Train future models on your personal code without explicit consent
- Share code data with third parties without permission
- Use data for purposes other than those stated here

## 3. Data Sharing

We only share data with:
- **Service Providers:** Third-party processors (e.g., cloud infrastructure, payment processors) under Data Processing Agreements
- **Legal Requests:** When required by law or court order
- **Your Explicit Consent:** When you authorize it

## 4. Security

We implement:
- Encryption in transit (TLS/HTTPS) and at rest
- Regular security audits and penetration testing
- API key rotation and access control
- Compliance with OWASP and industry best practices

We cannot guarantee 100% security; please report vulnerabilities to security@codeai.example.com.

## 5. User Rights (GDPR, CCPA)

You have the right to:
- **Access:** Request a copy of your data
- **Deletion:** Request permanent deletion of your account and data
- **Portability:** Export your data in a structured format
- **Opt-out:** Disable certain data collection features

Submit requests to privacy@codeai.example.com.

## 6. International Data Transfers

Data is stored in the US and processed globally. If you are in the EU, we rely on Standard Contractual Clauses for transfers.

## 7. Children

The Service is not intended for users under 13. We do not knowingly collect data from children.
